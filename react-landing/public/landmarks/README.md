# Landmark photos

These images power the hover / tap cards on the "Everything nearby" connectivity
list (homepage Location section + each project detail page). A row shows a card
only when it has a `photo` entry in `src/data/locationConnectivity.ts`; if the
file is missing the card still opens with a "Photo coming soon" placeholder.

Keep files landscape, ~1000px wide, under ~200 KB. Use pictures you have the
right to publish. For a Creative Commons image, set a `credit` string on that
entry (see the two railway-station photos).
